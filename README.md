# 李杜诗间

李白与杜甫诗句互文可视化，含电脑端与手机端。

入口： https://bessie-laptop.github.io/lidu-intertext-visualization/

- 屏幕宽度不超过 700px 自动进入手机端：lidu-site/mobile/
- 电脑端：lidu-site/dist/
- 两端入场动画均为 500 行诗句、约 10 秒。
- 手机端全屏阅读、双指缩放；电脑端保留侧栏阅读。
- 诗对保留原始匹配分句；展开全诗按句号换行。
- 收藏保存在当前浏览器中。

开发者：上海交通大学周书欣

数据来源：上海交通大学助理教授段思宇《数字人文导论》课程
